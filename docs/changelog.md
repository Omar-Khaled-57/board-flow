| Version | Headline from the changelog |

| v1.0.0 | Stats wave chart, 4-tier export chain, Android share and build fixes for a clean production build. |
| v0.8.2 | Android export via the Tauri save dialog (SAF), responsive date/time fields and accessibility fixes. |
| v0.8.0 | Android build fix, chunk splitting, per-notification icons and the initial unit-test suite. |

| v0.7.0 | Notes system: `/notes`, note details, rich insert editor, task linking and attachments. |

| v0.5.2 | Android export via native save dialog + FS plugin, daily goal notification, version display. |
