# BoardFlow visual identity

BoardFlow uses a friendly productivity palette: vivid periwinkle for action and
navigation, with a warm pink-and-yellow note in its light-first interface.
Dark mode retains the same blue identity against charcoal surfaces.

| Role | Color |
| --- | --- |

| Secondary | ![#8B1D4B](https://img.shields.io/badge/-%238B1D4B?style=flat-square&color=8B1D4B) `#8B1D4B` |

| Dark canvas / card | ![#1A1A1A](https://img.shields.io/badge/-%231A1A1A?style=flat-square&color=1A1A1A) `#1A1A1A` / `#222227` |
